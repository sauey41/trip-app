# 贝克旅行品牌素材

`primary-blue.svg`、`wordmark-blue.svg` 与 `icon-blue.svg` 原样使用用户提供的 2026.10 标志文件，原文件保留标准蓝 `#194A98`，文字已转为轮廓路径。

贝壳图形是主要识别：登录页、后台页头使用 72 px 图形标，前台页脚使用 168 px 完整标志，文字为辅助。保留原有路径、比例和安全留白，不拉伸、不添加滤镜或阴影。

按用户 2026-10-07 的新要求，网站支持随旅行主题变化的单色版本。动态 `/brand/*.svg?color=六位HEX` 只替换填充色，不修改原始素材。Logo 与页面的主要文字、按钮使用同一颜色；过浅的自定义色会自动加深，以确保可读性。未打开具体旅行时默认使用品牌蓝。

浏览器图标使用原贝壳图形等比置于浅色背景，并提供 SVG 和 PNG 两种格式、版本地址以避免旧图标缓存；切换旅行时同步图标颜色。群晖桌面图标为固定品牌蓝，不随网页中选择的旅行变化。浏览器和 DSM 的图标尺寸由平台指定；常规页面不使用这些小尺寸位图代替矢量标志。
